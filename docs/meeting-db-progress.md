## 로그

### 2026-10-16 — 2단계 (0.30.0) 저장 뷰

- 데이터베이스 위에 뷰 탭: 뷰마다 이름·필터·정렬·표시 속성을 따로 저장. 탭 옆 `+`로 추가, `⋯`로 이름 변경·복제·삭제. 뷰 설정은 블록에 저장되어 모두에게 같고, 마지막으로 연 탭은 브라우저별로 기억.
- 필터(모두 만족해야 표시): 제목·텍스트(포함/일치/비어 있음), 선택(같음/다름), 체크(체크됨/안 됨), 숫자 비교, 날짜(특정일·이전·이후·이상·이하·오늘·이번 주·최근 7/30일·이번 달·비어 있음). 미완성 규칙은 행을 숨기지 않음. "N of M"으로 남은 행 수 표시.
- 정렬: 최대 5개 규칙(제목·속성, 오름/내림), 빈 값은 항상 뒤. 정렬이 없으면 수동 순서 유지.
- 표시 속성: 뷰별로 속성 숨기기/보이기.
- 필터된 뷰에서 새 행을 만들면 필터 조건을 만족하는 값이 자동 입력(예: 유형=주간, 날짜=이번 주 → 오늘).
- 기존 DB는 기본 "Table" 뷰 1개로 동작(마이그레이션 불필요). 피드 레이아웃은 3단계에서 추가.

### 2026-10-16 — 1단계 (0.29.0) 속성·행 관리

- 속성 메뉴(⋯): 타입 변경 시 값 변환(텍스트→선택은 기존 값으로 선택지 생성, 숫자 파싱, 체크 → Yes/No), 선택지 추가·이름 변경(값이 따라감)·삭제(값 비움), 좌우 이동, 삭제(페이지 안에서 확인).
- 행 메뉴(⋯): 복제(하위 페이지까지 복사, 같은 값으로 바로 아래에 추가), 위·아래 이동, 삭제(행은 즉시 제거, 페이지는 휴지통 — 실패 시 행 복원).
- 메뉴는 표 스크롤 영역에 잘리지 않도록 화면 위 떠 있는 레이어로 표시(Esc·바깥 클릭·스크롤 시 닫힘).
- 발견·수정한 버그: 데이터베이스 편집 직후 행 페이지를 휴지통으로 보내면 “저장되지 않은 초안” 오류로 거부되던 문제 — 휴지통/복원은 부모 페이지를 바꾸지 않으므로 부모 초안을 기다리지 않도록 수정.
