## 로그

### 2026-10-16 — 1단계 (0.29.0) 속성·행 관리

- 속성 메뉴(⋯): 타입 변경 시 값 변환(텍스트→선택은 기존 값으로 선택지 생성, 숫자 파싱, 체크 → Yes/No), 선택지 추가·이름 변경(값이 따라감)·삭제(값 비움), 좌우 이동, 삭제(페이지 안에서 확인).
- 행 메뉴(⋯): 복제(하위 페이지까지 복사, 같은 값으로 바로 아래에 추가), 위·아래 이동, 삭제(행은 즉시 제거, 페이지는 휴지통 — 실패 시 행 복원).
- 메뉴는 표 스크롤 영역에 잘리지 않도록 화면 위 떠 있는 레이어로 표시(Esc·바깥 클릭·스크롤 시 닫힘).
- 발견·수정한 버그: 데이터베이스 편집 직후 행 페이지를 휴지통으로 보내면 “저장되지 않은 초안” 오류로 거부되던 문제 — 휴지통/복원은 부모 페이지를 바꾸지 않으므로 부모 초안을 기다리지 않도록 수정.
